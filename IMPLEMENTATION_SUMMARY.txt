================================================================================
                          DATABASE SCHEMA
================================================================================

resumes
├── id (UUID, PK)
├── filename (VARCHAR)
├── content (TEXT)
├── file_size_bytes (INTEGER)
└── created_at (TIMESTAMP)

analyses
├── id (UUID, PK)
├── resume_id (UUID, FK → resumes.id)
├── job_description (TEXT)
├── overall_score (INTEGER)
├── results_json (TEXT)
└── created_at (TIMESTAMP)

optimized_resumes
├── id (UUID, PK)
├── analysis_id (UUID, FK → analyses.id)
├── content (TEXT)
├── format (VARCHAR)
└── created_at (TIMESTAMP)

reports
├── id (UUID, PK)
├── analysis_id (UUID, FK → analyses.id)
├── file_path (VARCHAR)
├── report_type (VARCHAR)
└── created_at (TIMESTAMP)

================================================================================
                        HOW TO GET STARTED
================================================================================

QUICK START (5 minutes):
1. pip install -r requirements.txt
2. docker run --name resume_advisor_db \
     -e POSTGRES_PASSWORD=postgres \
     -e POSTGRES_DB=resume_advisor \
     -p 5432:5432 -d postgres:15
3. echo "DATABASE_URL=postgresql://postgres:postgres@localhost:5432/resume_advisor" > .env
4. python init_db.py
5. uvicorn main:app --reload
6. Visit http://localhost:8000

DETAILED SETUP:
→ See DATABASE_SETUP.md for comprehensive instructions
